# Дашборд: учебный маршрут

Здесь лежит каркас, который ты постепенно реализуешь сам. Начинаем с Python:
одна строка JSON, затем файл, затем вывод в терминале. Первая страница появится
после того, как чтение и сводка уже работают.

Полный план и уроки находятся в папке **Дашборд OpenCode** выбранного Obsidian Vault.
`currentsteps.md` в корне Vault хранит текущий подшаг и последние результаты.

## Что открывать сейчас

Активная функция и первое действие указаны в **currentsteps.md** в корне Vault.
Отдельный текущий статус здесь не дублируем. Порядок этапов - в заметке
**02. План разработки**, упражнения сводки и страницы - в заметке
**04. Этапы 2 и 3. Сводка и страница**. Таблица ниже - повторение первого этапа.

Русские подсказки находятся в заметках Obsidian, а не в коде: основной урок 04
и справочник **06. Подсказки к функциям**. В коде остаются английские спецификации.
Подсказки содержат цель, пример и небольшие действия по порядку. Сначала
пробуй пункт 1, а не всю функцию сразу. Если пункт отмечен как промежуточный опыт,
итоговый тест ещё может не пройти. «Позже» означает: текущую функцию менять не нужно.

## После первого этапа

`work_item` — задание исполнителю, например реализация одного класса. Функция
`work_items()` позже соберёт историю этих заданий; `work_item_count` в полной
сводке будет их количеством. Повторные попытки одного задания не увеличивают
число заданий. Старое поле журнала `piece` уже преобразуется в `work_item`
при чтении; исторические файлы менять не нужно.

1. `task_status`, `test_runs`, `brief_summary`: краткая сводка одной задачи без сложной истории заданий.
2. `simple.py` и `static/simple.html`: сервер с двумя адресами, одна страница, кнопка обновления.
3. Несколько задач, история заданий и лимиты: постепенно подключаем старые модули.
4. Экспорт OpenCode, токены, кэш и живая лента.
5. Автообновление, затем настройки моделей с защитой POST.
6. Отдельный этап React при желании: Python API остаётся прежним.

`py -m kit.dashboard` — будущий полный сервер. Его старые номера `step 1.x` ...
`step 10.x` обозначают прежний план, а не новый порядок обучения.
`JournalTail`, `work_items`, `guard_status`, `summary`, остальные серверные модули
и полная `static/app.js` понадобятся позже.

`py -m kit.dashboard.simple ...` тоже пока каркас. Запускай сервер после завершения
его учебного этапа; готового работающего сайта сейчас нет.

Пишем обычные `for` и `if`, пользуемся явными переменными. Краткость не является
критерием качества. Помощник проверяет код, объясняет ошибки и готовит следующий урок.
